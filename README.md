# 🔷 Hexagon Slingshot Physics Game

A 2D physics projectile game built with **Matter.js** body constraints, **p5.js**, and custom sprite texturing. Launch a hexagon projectile using a physics chain constraint to knock down target blocks.

![Matter.js](https://img.shields.io/badge/Matter.js-black?style=for-the-badge)
![p5.js](https://img.shields.io/badge/p5.js-ED225D?style=for-the-badge&logo=p5dotjs&logoColor=white)

## 🎯 Features
- ⛓️ **Elastic Chain Slingshot**: Uses `chain.js` constraint physics for pullback and release motion.
- 🛑 **Target Block Grid**: Multi-layer target structures built with `Block.js`.
